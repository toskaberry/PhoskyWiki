# 0007 — 视角平等并列与取消编委会

- 状态：已接受，2026-09-11；实现与迁移已编写，正式环境清理随部署执行。

哲学内容通过不同诠释者对概念的分歧展开，站点不设代表站方的指导性解释。因此取消编委会这一特殊诠释者、固定首位和默认通俗视角，并取消面向所有读者的公共视角置顶；读者兴趣和普通排序规则不代表站方授予某个视角权威。

新建词条只创建导航元数据；解释正文另行归入具名诠释者视角，不要求同时创建首篇视角，也不以另一种默认解释替代编委会。

用户明确选择彻底删除既有编委会视角及其历史，不将其改名保留为普通公开视角，也不保留可恢复档案。编委会页面及其相关内容的清理是 ADR-0004 正常删除保留历史规则的一次明确例外；其他页面的正常删除与修订规则继续适用。清理应核对相关链接和待审提交，避免公开入口或待审内容重新引入已取消的角色。
