# 图谱布局与学派群落

2026-09-11：通过 grill-with-docs 讨论及真实数据交互原型确认的产品选择。全站与局部图谱共用正式实现：Worker 计算柔和群落，SVG 呈现实心饼图与可聚焦词条，拖拽时进行圆形碰撞处理。

## 范围与布局

- 同时优化全站图谱与词条页的 1/2 跳局部图谱。
- 使用柔和、可交叠的学派群落，综合各学派成员视角和词条双链安排位置。跨学派词条连接多个群落，每个词条始终只有一个节点。
- 群落以淡化的色彩提示呈现，不用硬边界划分概念归属。缺少学派成员视角的词条依双链关系分布，不强制组成独立分区。
- 优先保证舒适间距，允许缩放和平移；不要求首屏同时读清全部节点。名称按空间显示，悬停或选中时提供完整词条名称。
- 拖动节点时，周围节点自动避让，松手后稳定。圆点之间不重叠；连线弱化，交互时突出直接关联。

## 节点样式：实心饼图

- 多学派词条使用实心饼图，扇区沿用学派颜色，面积按该词条各学派成员视角计数分配。
- 单学派词条呈现对应颜色的实心圆；暂无学派成员视角的词条使用灰色实心圆。
- 保留热度与节点大小的对应关系，并限制最大尺寸。
- 选中词条时显示涉及的学派及各自成员视角数量，并突出相关群落和直接关联。
- 触屏轻触先选中，由详情中的“进入词条”按钮导航；鼠标点击与键盘 Enter 保留直接导航。详情支持滚动，完整标题和所有学派计数均可访问。
- 一个诠释者可能属于多个学派，成员视角计数可能交叉。扇区表达站内已收录视角的构成信号，不表示概念归属比例、学派独占性或内容完整度。
- 圆环、中性色多学派节点与渐变色均为已比较的备选，正式方案采用实心饼图。

## 正式实现的验收

- 全站与局部视图在初始布局、拖拽、缩放、容器尺寸变化后，均检查屏幕上节点圆形边界的实际间距；不能仅依赖增大斥力或隐藏标签。
- 同一词条保留唯一节点及既有导航目标，保留搜索定位、邻居导航和局部跳数切换。
- 多学派节点保留全部有效学派的计数，不再仅凭主导学派决定群落位置。
- 分别验证单学派、多学派、暂无学派视角、孤立节点和密集网络。原型数据包含 217 个词条、2,987 条边，其中 84 个词条有多学派视角、110 个暂无学派成员视角；这些是当时本地数据，不是展示上限。
- 交互原型用于确认视觉方向；正式实现验证布局性能、可访问性、标签碰撞及既有图谱交互。
